# Generated game sprites

Created using the built-in image generation tool. Transparent PNGs; independent objects used in the Remotion demos. These are presentation examples, not requirements for the final game art.

## player.png

Use case: stylized-concept / production 2D game sprite. Create exactly ONE isolated top-down orthographic spaceship sprite: Player spaceship, nose pointing UP, compact arrowhead silhouette, cyan blue hull with white fins, one blue engine nozzle pointing down. Art direction: polished hand-painted 2D arcade shooter, crisp sharp edges, restrained cel shading, high legibility at 100 pixels, consistent light from upper left, no perspective angle, centered with generous empty padding on all sides. The spaceship occupies 70 percent of the canvas. Truly transparent background, no environment, no stars, no floor, no text, no letters, no HUD, no watermark, no other ships, no projectiles, no trails. This is a reusable sprite asset to move independently in a game specification demo, not a scene or poster.
